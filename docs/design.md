Design Direction

| Dimensi | Keputusan | Implikasi desain |
|---|---|---|
| Identitas visual | Futuristic | Digital interface, teknologi, cyber aesthetic |
| Pengalaman | Interactive | Animasi, micro-interaction, respons visual |
| Pengalaman | Explorative | Navigasi dan konten mendorong eksplorasi |
| Audiens | Developer & komunitas teknologi | Proyek, teknologi, source code, dokumentasi |
| Audiens | Gamer & komunitas kreatif | Game, eksperimen, desain, karya kreatif |

Arah Visual
Foundation: dark futuristic interface.
Atmosphere: cyber, digital, sedikit sci-fi.
Layout: kombinasi editorial layout, modular cards, dan immersive sections.
Interaction: hover feedback, transition, scroll animation, interactive components.
Typography: kombinasi display futuristic dan sans-serif yang mudah dibaca.
Visual assets: ilustrasi, artwork, iconography, dan elemen digital.

UI/UX
Layer 1 — Discover

Pengunjung mengenal identitas, kemampuan, dan aktivitas melalui halaman utama.

Layer 2 — Explore

Pengunjung menjelajahi proyek, game, eksperimen, desain, dan pengetahuan.

Layer 3 — Connect

Pengunjung mengakses GitHub, komunitas, media sosial, dokumentasi, serta kontak.
