# 1.1 Tujuan Proyek
    Memperkenalkan identitas personal
    Menampilkan proyek nyata beserta kontribusi dan keputusan teknisnya.
    Menjelaskan kemampuan berdasarkan bukti, bukan sekadar daftar teknologi.
    Menampilkan proses berpikir dan pendekatanmu dalam menyelesaikan masalah.
    Menjadi pusat navigasi menuju GitHub, demo proyek, dokumentasi, dan kontak.
    Menjadi tempat mendokumentasikan eksperimen dan eksplorasi teknologi.
    Mendukung personal branding untuk kesempatan kerja, kolaborasi, dan bisnis digital.
    Tetap mudah dikembangkan ketika jumlah proyek dan kemampuanmu bertambah.
    Menampilkan dunia digital dari imajinasi dari kepala

# 1.2 Target Pengunjung
    Recruiter	Identitas, kemampuan, pengalaman, dan proyek yang relevan
    Developer	Kualitas kode, arsitektur, dokumentasi, dan repository
    Calon klien	Layanan, hasil pekerjaan, contoh karya, dan kontak
    Komunitas developer	Eksperimen, proyek open-source, dan peluang kolaborasi

#  1.4 Kriteria Keberhasilan
Portofolio dianggap siap dipublikasian ketika:
    Semua tautan utama berfungsi
    Seluruh proyek yang ditampilkan memiliki informasi yang benar
    Layout bekerja pada dekstop, tablet, dan ponsel
    Konten dapat diakses menggunakan keyboard
    Tidak ada kesalahan JavaScript yang belum diselesaikan
    Gambar dan font tidak menyebabkan beban yang tidak perlu
    Halaman memiliki metadata dan judul yang sesuai
    Repositori berisi dokumentasi yang cukup untuk pemeliharaan
    Deployment berjalan sesuai konfigurasi hosting
