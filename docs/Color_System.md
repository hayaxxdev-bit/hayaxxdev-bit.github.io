# 3.2 Pembagian penggunaan warna 
Menggunakan prinsip hierarki visual
 Background gelap dan mendominasi halaman
 Teks utama menggunakan warna terang yang nyaman dibaca
 Dark red digunakan untuk penekanan dan elemen interaktif tertentu
 Dark purple digunakan untuk variasi permukaan, ilustrasi, dan atsmosfer
 Golden white digunakan secara terbatas untuk highlight, garis dekoratif, dan detail panjang

# 3.3 Gradiant System
Primary gradient
 Merah gelap menuju ungu gelap, untuk elemen dekoratif atau latar visual tertentu.

Atmospheric gradient
 Ungu gelap menuju warna background, untuk menciptakan kedalaman.

Highlight gradient
 Golden white menuju transparan, untuk pencahayaan halus pada elemen terpilih.

# 3.4 Sistem transparasi 
 Transparasi digunakan berdasarkan kebutuhan komponen
 contoh
  1. Border transparan untuk pemisah panel
  2. Overlay gelap untuk gambar latar
  3. Permukaan transparan untuk elemen dekoratif
  4. Glow tipis pada elemen fokus
