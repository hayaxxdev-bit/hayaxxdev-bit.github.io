# 03 — Featured Projects

| Field           | Isi                                             |
| --------------- | ----------------------------------------------- |
| `id`            | Identitas unik proyek                           |
| `name`          | Nama proyek                                     |
| `summary`       | Ringkasan singkat                               |
| `category`      | Web, Application, Game, Library, dan sebagainya |
| `role`          | Kontribusimu pada proyek                        |
| `technologies`  | Teknologi yang benar-benar digunakan            |
| `status`        | Development, Active, Completed, Archived        |
| `thumbnail`     | Gambar representatif                            |
| `repositoryUrl` | URL repository                                  |
| `demoUrl`       | URL demo jika tersedia                          |
| `featured`      | Apakah proyek ditampilkan sebagai unggulan      |

Informasi pada kartu proyek:

- Thumbnail.
- Nama.
- Ringkasan.
- Kategori.
- Teknologi utama.
- Status.
- Tautan detail atau repository.
